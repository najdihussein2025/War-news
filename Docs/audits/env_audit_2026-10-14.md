## Recommendations for Phase 1–3

### Phase 1: Move TUNING to Settings
1. Ensure all TUNING variables have Settings fields with appropriate defaults
2. Replace direct `os.getenv` calls in app code with settings references
3. Add missing TUNING fields to Settings (SUPER_ADMIN_SEED_*, WEBHOOK_*, ACCURACY_STUDY_*)

### Phase 2: Restructure .env.example
1. Split into sections: Required secrets, Per-environment, Per-service, Optional tuning
2. Comment out tuning overrides with defaults shown
3. Remove DEAD variables (none found)
4. Update conflicting example values to match actual deploy defaults

### Phase 3: Prove effective config is unchanged
1. Write `print_effective_config.py` to load Settings with current and updated config
2. Verify no difference in non-secret values before and after
3. Test on dev stack, simulate deploy stack
